# Fieldnotes — Research Methodology

A static, chapter-based study companion for the NPTEL IIT Madras course **Research Methodology** (course ID 121106007).

## Deploy to Vercel

This project has no build step or runtime dependencies. Import this folder as a project in Vercel and deploy it with the defaults (Framework Preset: **Other**, Build Command: blank, Output Directory: `.`). `index.html` is the site entry point. The included `vercel.json` keeps URLs clean.

## Included

- Eight course chapters with at least 1,500 words of exam-oriented study notes each, based on the supplied course transcript PDF.
- Full-screen chapter study pages with lessons, notes, and a three-question interactive self-check with feedback and explanations.
- Chapter notes and completion progress saved in the browser's local storage.
- Search across chapters, lessons and test questions.
- Links to the provided lecture, the official course page, and a YouTube search for the full course playlist.

The test items are original practice questions based on the chapter topics and lecture material. They are not presented as verbatim NPTEL assessment questions. YouTube did not expose the linked video's transcript or playlist metadata in the available lookup, so the playlist link opens a YouTube search for the course title.
